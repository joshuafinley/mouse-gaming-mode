# Mouse Gaming Mode

The website for Mouse Gaming Mode, a Mac menu bar app that makes your mouse game-ready: PC-style wheel scrolling with zero added latency, a natural trackpad, and fixes for Shift + scroll and Control-click in games.

- Website: https://joshuafinley.github.io/mouse-gaming-mode/
- Support and bug reports: open an issue here.
- Privacy: https://joshuafinley.github.io/mouse-gaming-mode/privacy.html
